## Download

<div align="center">

### [⬇&nbsp;&nbsp;Download MacPulse](https://github.com/borissharikoff-droid/MacPulse/releases/latest)

<sup>macOS 13 or newer · Apple Silicon and Intel · 3 MB</sup>

</div>

**Easiest — paste this into Terminal, press Enter, done:**

```bash
curl -fsSL https://raw.githubusercontent.com/borissharikoff-droid/MacPulse/main/install.sh | bash
```

It downloads, installs to Applications and starts the app. No warnings, nothing else to click.

**Or by hand:** download `MacPulse-1.0.0.dmg` from the link above, open it, drag **MacPulse** onto **Applications**. The first launch shows *"Apple could not verify…"* — that is expected (the app is free and unsigned by Apple). Fix it once: **System Settings → Privacy & Security →** scroll down **→ Open Anyway**.

<sub>Uninstall: `curl -fsSL https://raw.githubusercontent.com/borissharikoff-droid/MacPulse/main/install.sh | bash -s -- --uninstall`</sub>
